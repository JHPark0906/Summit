# 말풍선

[SpeechBubble](../Source/UI/SpeechBubble.cpp)은 말한 플레이어의 자식 객체로 마지막 메시지를 잠시 표시한다. 채팅 패널은 원문을 유지하고 말풍선은 최대 48개 Unicode 코드 포인트를 남긴 뒤 말줄임표를 붙인다. 메시지가 바뀌면 같은 객체를 재사용하고 기본 6초의 수명을 다시 시작한다.

이 문서는 코드의 표시 정책을 설명한다. 원래 캐릭터 아틀라스와 글꼴은 공개본에 포함되지 않으며, 아래의 콘텐츠 검사는 해당 자산을 별도로 준비해야 실행할 수 있다.

## 텍스트 측정과 수명

`LayoutElement`로 줄바꿈 없는 폭을 먼저 측정한다. 이를 최대 240 논리 픽셀로 제한한 뒤 같은 레이아웃 경로에서 줄바꿈 높이를 구한다. 짧은 메시지 → 긴 메시지 → 짧은 메시지 교체마다 두 크기를 다시 계산하며, 필요한 레이아웃 갱신 전에는 이전 크기로 그리지 않는다.

| 항목 | 코드의 값 |
| --- | --- |
| 기본 표시 시간 | 6초 |
| 본문 상한 | 48 코드 포인트 뒤 말줄임표 |
| 최대 본문 폭 | 240 논리 픽셀 |
| 본문 글꼴 크기 | 22 |
| 텍스트 월드 배치 기준 | 월드 단위당 55픽셀 |
| 배경 여백 | 좌우 각각 6픽셀, 상하 각각 4픽셀 |
| 머리 앵커와 배경 사이 | 0.16 월드 단위 |

말풍선은 world-space UI이며, 측정에는 엔진의 기존 글꼴·레이아웃 캐시를 사용한다. Sprite의 Visual 객체가 아닌 플레이어 루트에 붙이므로 캐릭터가 좌우로 뒤집혀도 텍스트는 뒤집히지 않는다. 자식 객체는 Scene이 소유하고, 컴포넌트는 ID로 다시 조회해 삭제된 자식의 포인터를 유지하지 않는다.

## 캐릭터 앵커와 교체 자산

구현의 `SpriteHeadAnchor` 표는 기존 아틀라스 참조와 프레임별 머리 위치를 담고 있다. `SpriteRenderer::ResolveFrame()`이 현재 프레임을 선택하므로 ping-pong 재생도 같은 경로를 사용한다. 머리 위치에 캐릭터 Visual의 오프셋과 배율을 적용한 뒤 그 위에 말풍선을 배치한다. 컴포넌트가 실행 중 PNG를 열어 머리 위치를 다시 찾는 방식은 아니다.

알려지지 않은 아틀라스는 플레이어 콜라이더의 위쪽을 기준으로 삼는다. 콜라이더가 없는 원격 플레이어의 대체 오프셋은 1.28 월드 단위다. 그림을 교체할 때는 [PlayerController의 자산 참조](../Source/Gameplay/PlayerController.h), 프레임 배치, pixels-per-unit, 발·머리 앵커를 함께 맞춘다. 기존 표의 값이 다른 그림의 머리 위치를 보장하지 않는다.

## 테스트

[SpeechBubbleTests.cpp](../Tests/SpeechBubbleTests.cpp)는 UI 배율 1·2에서 짧은/긴/다시 짧은 메시지의 측정 크기와 아틀라스 픽셀 기준 앵커를 검사한다. [ChatVisualTests.cpp](../Tests/ChatVisualTests.cpp)는 D3D11/12와 두 배율에서 말풍선 캡처를 만든다. 원격 메시지의 플레이어 ID 연결과 퇴장 정리는 [ChatNetworkTests.cpp](../Tests/ChatNetworkTests.cpp)가 다룬다.

테스트에는 원래 회귀 씬·글꼴·캐릭터 아틀라스가 필요하다. 실행 조건은 [빌드와 콘텐츠 준비](Distribution.md), 실제 실행 기록은 [검증 결과](VALIDATION.md)를 참고한다.
